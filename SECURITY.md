# Security policy

## Supported version

The default branch is the supported version. Historical release assets are immutable records and do
not receive in-place fixes.

## Reporting

Use GitHub private vulnerability reporting for this repository. Do not place credentials, private
person data, exploit details, or the privacy salt in a public issue.

Include the affected path, a minimal reproduction, expected behavior, observed behavior, and whether
the issue can change a published claim or release asset. Article XIII privacy reports are treated as
publication incidents.

## Response

The maintainer will preserve evidence, assess published impact, add a regression test, and use the
public corrections process when a published artifact was affected. Silent history edits are not a
security response.
