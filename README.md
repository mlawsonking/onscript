# PoliSpeak (working name)

Daily automated distillation of what each U.S. party's elected officials actually said — one composite voice per party, every claim backed by real citations — plus the coordination machinery underneath: talking-point adoption curves, the silence map, and the on-script index.

**Status:** pre-build. Phase docs live in [`docs/`](docs/). Project charter, workflow, and constraints live in [`CLAUDE.md`](CLAUDE.md).

Predecessor (2022): [PoliticianTweeting](https://github.com/mlawsonking/PoliticianTweeting).
