# OnScript brand assets

The mark is a seismograph burst with echo traces: many voices, one script.

**Party composites** (`blue.onscript.news` / `red.onscript.news`): identical geometry for both
parties. Only the field color differs, making the symmetric method visible.
- Blue field `#1D4E89` · Red field `#A6192E` · Trace `#FAFAF7`

**House account** (`@onscript.news`, the apex): the parent of the two composites. It uses a neutral slate
field with the two parties' colors as **symmetric echoes** (blue fanning up, red fanning down)
converging into one white voice. Source of weekly awards, the nightly symmetry audit, and
postmortems (§7.4 / Operations).
- Field `#2E3138` · echoes `#1D4E89` (up) / `#A6192E` (down) · Trace `#FAFAF7`

Sizes: `avatar-*.png` 1000×1000 (Bluesky avatar, circle-crop safe) · `banner-*.png` 1500×500.

`brand.py` is committed and deterministic (pure math, no RNG). It regenerates the **house** pair at any size.
The party pair were generated by an earlier scratchpad script; the committed PNGs are canonical.
